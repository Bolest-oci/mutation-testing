# Use Case: 05.4 - Verify Test Improvements

## Description
This use case describes how the agent verifies that test fixes successfully
kill previously surviving mutants.  
The system supports **Default**, **Advanced**, and **Custom** verification flows.

## Actor
RooCode Agent

## Preconditions
- Test fixes have been applied and committed.
- Cosmic Ray is installed and configured.
- (Optional) Mutant tracking file exists from previous flows.

## Flow

1. **Select Verification Flow**
   - Agent asks the user which flow to execute:
     - **Default** → simple linear verification of previously surviving mutants.
     - **Advanced** → enhanced verification with mutant tracking, safe execution, reporting, and optional notifications.
     - **Custom** → user-provided workflow for verification.

### Default Flow

2. **Re-run Targeted Mutation Tests**
   - Agent runs mutation tests targeting previously surviving mutants:
     ```bash
     cosmic-ray run cosmic-ray.toml --baseline=previous
     ```

3. **Compare Results**
   - Agent compares new results against the previous mutation run.
   - Agent identifies mutants that are now killed.

4. **Report Outcome**
   - Agent reports:
     - Improved mutation score
     - Mutants resolved
     - Any remaining survivors

### Advanced Flow (Actionable)

2a. **Filter Mutants Using Tracking**
   - Agent reads mutant tracking file.
   - Only runs verification for mutants with status `fixed` or `pending verification`.

3a. **Safe Mutation Test Execution**
   - Agent backs up previous mutation results.
   - Runs targeted mutation tests safely.
   - Logs any execution errors for user review.

4a. **Compare and Update Mutant Status**
   - Agent compares new results against the previous run.
   - Updates mutant tracking file:
     ```
     mutant_id | verified | timestamp | test_file
     ```
   - Marks mutants that remain alive for further investigation.

5a. **Enhanced Reporting**
   - Agent generates a report including:
     - Mutation score improvement
     - List of killed mutants with associated test files
     - Remaining survivors and risk scores
     - Historical trend of verification runs
   - Optional notifications to team members.

6a. **Explain Rationale**
   - Agent includes rationale for why fixes successfully killed each mutant.

### Custom Flow

2b. **Execute Custom Verification**
   - Agent executes user-provided workflow.
   - Custom flow may redefine steps, output format, or mutant tracking.
   - If essential outputs (e.g., verification results or rationale) are missing, agent ensures they are produced.

## Postconditions
- Verification results are available.
- Mutant tracking file is updated to reflect verified mutants.
- Confidence in test improvements is established.
- Optional reports or notifications provide visibility on remaining mutants.
