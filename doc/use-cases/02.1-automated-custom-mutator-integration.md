# Use Case: 02.1 - Automated custom mutator integration

## Description
This use case automates the process of integrating and running custom mutators with Cosmic Ray. The RooCode agent will first identify available custom mutators, then prompt the user to select which ones to integrate. Once selected, the agent will configure and run Cosmic Ray with the chosen mutators and generate a report.

## Actor
RooCode Agent

## Preconditions
- A Cosmic Ray configuration file exists (e.g., `cosmic-ray.toml`).
- One or more custom mutators are available in the project.

## Flow

1.  **Discover Available Custom Mutators:**
    - The agent scans the project's filesystem for directories that appear to be custom mutator packages, rather than relying on `cosmic-ray operators`, which only lists already installed mutators.
    - It presents a list of discovered mutators to the user.

2.  **User Selects Mutators:**
    - The user selects one or more mutators from the list to be integrated.

3.  **Determine Operator Keys:**
    - The agent inspects the `provider.py` file within each selected custom mutator's package to identify the correct operator key.

4.  **Configure Cosmic Ray for Selected Mutators:**
    - The agent modifies the Cosmic Ray configuration file to include the selected custom mutators.
    - It will configure the `[cosmic-ray.filters.operators-filter]` to ensure only the selected mutators are used.

4.  **Run Mutation Testing:**
    - The agent executes the mutation testing process using the updated configuration.
    - It runs Cosmic Ray to apply the mutations and execute the test suite against them.

5.  **Generate and Present Report:**
    - Upon completion, the agent generates an HTML report of the mutation testing results.
    - The report is saved, and the user is notified of its location.

## Postconditions
- The Cosmic Ray configuration is updated to use the user-selected custom mutators.
- Mutation testing has been successfully executed.
- An HTML report detailing the results is generated and available to the user.
