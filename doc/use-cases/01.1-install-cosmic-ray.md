# Use Case: 02.1 - Install Cosmic Ray

## Description
This use case describes the process for intelligently installing the Cosmic Ray mutation testing framework into a target project. The agent will analyze the project's existing dependency management tools and use the appropriate method for installation.

## Actor
RooCode Agent

## Preconditions
- The project has been set up as a submodule in `repos/<project_name>`.
- A patch file exists at `_spikes/cosmic-ray-changes.patch`.
- The agent is currently in the `repos/<project_name>` directory.

## Flow
1.  **Prepare Patched Cosmic Ray Toolchain:**
    - The agent must first setup the local Cosmic Ray repository with custom patches.
    - **Clone and Patch:**
      - Agent navigates to the workspace root:
        ```bash
        cd ../..
        ```
      - Agent clones the official repository as a sibling submodule:
        ```bash
        git submodule add https://github.com/sixty-north/cosmic-ray.git repos/cosmic-ray
        ```
      - Agent navigates to the new directory:
        ```bash
        cd repos/cosmic-ray
        ```
      - Agent applies the custom patch:
        ```bash
        git apply ../../_spikes/cosmic-ray-changes.patch
        ```
      - **Verification:** Agent runs `git status` to confirm the patch has modified the files.

    - **Return to Target Project:**
      - Agent navigates back to the target project directory to proceed with installation:
        ```bash
        cd ../../repos/<project_name>
        ```

2.  **Analyze Project Structure:**
    - Agent inspects the project for common Python dependency management files, in the following order of preference:
        - `pyproject.toml` (with a `[tool.uv]` section) or `uv.lock`
        - `pdm.lock` or `pyproject.toml` (with a `[tool.pdm]` section)
        - `poetry.lock` or `pyproject.toml` (with a `[tool.poetry]` section)
        - `Pipfile` or `Pipfile.lock`
        - `requirements.in` or `requirements.txt` (managed by `pip-tools`)
        - A `venv` or `.venv` directory.

3.  **Select Installation Strategy (Local Source):**
    - The agent installs the package from the local path `../cosmic-ray` (instead of PyPI).
    - **If `uv` is detected:**
        - Agent runs: `uv add --dev --editable ../cosmic-ray`
    - **If `pdm` is detected:**
        - Agent runs: `pdm add -d --editable ../cosmic-ray`
    - **If `poetry` is detected:**
        - Agent runs: `poetry add --editable ../cosmic-ray --group dev`
    - **If `pipenv` is detected:**
        - Agent runs: `pipenv install -e ../cosmic-ray --dev`
    - **If `pip-tools` is detected:**
        - Agent adds `-e ../cosmic-ray` to `requirements.in` (or development requirements file).
        - Agent runs `pip-compile` and `pip-sync`.
    - **If a virtual environment (`venv`) is detected:**
        - Agent activates the virtual environment (e.g., `source venv/bin/activate`).
        - Agent runs: `pip install -e ../cosmic-ray`
    - **If a dependency manager is detected but not installed:**
        - Agent follows the steps outlined in **Use Case 02.1.1 - Handle Missing Dependency Manager**.
    - **If no specific system is found:**
        - Agent creates a new venv (`python -m venv venv`), activates it, and runs: `pip install -e ../cosmic-ray`.

4.  **Synchronize Dependencies:**
    - After adding Cosmic Ray to the project's dependencies, the agent must ensure all dependencies are installed and synchronized.
    - **If `uv` is detected:**
        - Agent runs `uv sync`.
    - **If `pdm` is detected:**
        - Agent runs `pdm sync`.
    - **If `poetry` is detected:**
        - Agent runs `poetry install`.
    - **If `pipenv` is detected:**
        - Agent runs `pipenv install`.
    - **If `pip-tools` is detected:**
        - Agent runs `pip-sync` (if not already run in step 3).
    - **If a virtual environment (`venv`) is detected:**
        - No additional sync needed.
    - **Verification:** The sync command should complete successfully.

5.  **Verify Installation:**
    - After the installation command is run, the agent executes:
      ```bash
      pip show cosmic-ray
      ```
    - **Verification:** The command should return a path, and the "Editable project location" should point to the `.../repos/cosmic-ray` directory. If the command fails or returns an unexpected path, the installation is considered failed.

## Postconditions
- The official Cosmic Ray repo is cloned and patched in `repos/cosmic-ray`.
- Cosmic Ray is successfully installed within the project's dependency management system using the local source.
- The project's lock files or requirements files are updated to include Cosmic Ray.
