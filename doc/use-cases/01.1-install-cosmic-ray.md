# Use Case: 01.1 - Install Cosmic Ray

## Description
This use case describes the process for intelligently installing the Cosmic Ray mutation testing framework into a target project. The agent will analyze the project's existing dependency management tools and use the appropriate method for installation.

## Actor
RooCode Agent

## Preconditions
- The project has been set up as a submodule in `repos/<project_name>`.
- The agent is currently in the `repos/<project_name>` directory.

## Flow
1.  **Analyze Project Structure:**
    - Agent inspects the project for common Python dependency management files, in the following order of preference:
        - `pyproject.toml` (with a `[tool.uv]` section) or `uv.lock`
        - `pdm.lock` or `pyproject.toml` (with a `[tool.pdm]` section)
        - `poetry.lock` or `pyproject.toml` (with a `[tool.poetry]` section)
        - `Pipfile` or `Pipfile.lock`
        - `requirements.in` or `requirements.txt` (managed by `pip-tools`)
        - A `venv` or `.venv` directory.

2.  **Select Installation Strategy (Direct from Fork):**
    - The agent installs the package directly from the GitHub fork URL.
    - **If `uv` is detected:**
        - Agent runs: `uv add --dev git+https://github.com/RichardMacko/cosmic-ray.git`
    - **If `pdm` is detected:**
        - Agent runs: `pdm add -d git+https://github.com/RichardMacko/cosmic-ray.git`
    - **If `poetry` is detected:**
        - Agent runs: `poetry add git+https://github.com/RichardMacko/cosmic-ray.git --group dev`
    - **If `pipenv` is detected:**
        - Agent runs: `pipenv install git+https://github.com/RichardMacko/cosmic-ray.git --dev`
    - **If `pip-tools` is detected:**
        - Agent adds `git+https://github.com/RichardMacko/cosmic-ray.git` to `requirements.in` (or development requirements file).
        - Agent runs `pip-compile` and `pip-sync`.
    - **If a virtual environment (`venv`) is detected:**
        - Agent activates the virtual environment (e.g., `source venv/bin/activate`).
        - Agent runs: `pip install git+https://github.com/RichardMacko/cosmic-ray.git`
    - **If a dependency manager is detected but not installed:**
        - Agent follows the steps outlined in **Use Case 01.1.1 - Handle Missing Dependency Manager**.
    - **If no specific system is found:**
        - Agent creates a new venv (`python -m venv venv`), activates it, and runs: `pip install git+https://github.com/RichardMacko/cosmic-ray.git`.

3.  **Synchronize Dependencies:**
    - After adding Cosmic Ray to the project's dependencies, the agent must ensure all dependencies are installed and synchronized.
    - **If `uv` is detected:**
        - Agent runs `uv sync`.
    - **If `pdm` is detected:**
        - Agent runs `pdm sync`.
    - **If `poetry` is detected:**
        - Agent runs `poetry install`.
    - **If `pipenv` is detected:**
        - Agent runs `pipenv install`.
    - **If `pip-tools` is detected:**
        - Agent runs `pip-sync` (if not already run in step 3).
    - **If a virtual environment (`venv`) is detected:**
        - No additional sync needed.
    - **Verification:** The sync command should complete successfully.

4.  **Verify Installation:**
    - After the installation command is run, the agent executes:
      ```bash
      pip show cosmic-ray
      ```
    - **Verification:** The command should return a path, and the "Location" should indicate an installation from the GitHub repository (e.g., via a `.git` egg-link or similar reference). If the command fails or returns an unexpected path, the installation is considered failed.

## Postconditions
- Cosmic Ray is successfully installed within the project's dependency management system directly from the GitHub fork URL.
- The project's lock files or requirements files are updated to include Cosmic Ray.
