# Use Case: 03.1 – Detect Relevant Code Changes

## Description
This use case describes how to identify relevant code changes that should be considered for targeted mutation testing.

## Actor
RooCode Agent

## Preconditions
- A baseline branch or commit is available for comparison.
- The project repository is under version control.

## Flow
1. Agent executes a version control diff between the baseline and the current state.
2. Agent identifies modified files.
3. Agent extracts exact changed line ranges for each modified file.
4. Agent ignores:
   - whitespace-only changes,
   - non-code files.
5. Agent produces a list of candidate files and corresponding line ranges.
6. If the resulting list is empty, the agent signals termination of the parent use case.

## Verification
- At least one code file with at least one changed line range is identified.

## Postconditions
- A filtered list of relevant files and line ranges is available for further processing.
