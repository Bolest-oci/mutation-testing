# Use Case: 06.1 - Apply Test Fixes

## Description
This use case describes how approved test fixes are applied to the codebase.

## Actor
RooCode Agent

## Preconditions
- Test fix proposals have been reviewed and approved by the user.
- The agent has write access to test files.

## Flow
1. **Modify Test Files**
   - Agent updates existing test files according to the approved proposal.
   - Agent follows existing test conventions and formatting.

2. **Run Test Suite**
   - Agent executes the full test suite.
   - **Verification:** All tests must pass.

3. **Commit Test Changes**
   - Agent stages modified test files.
     ```bash
     git add tests/
     ```
   - Agent commits changes:
     ```bash
     git commit -m "test: Improve tests based on mutation analysis"
     ```

## Postconditions
- Tests are updated and passing.
- Changes are committed to the mutation-testing branch.
