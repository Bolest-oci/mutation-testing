# Use Case: 03.3 – Optimize Mutation Scope

## Description
This use case describes how the mutation testing scope is optimized by first restricting mutations to changed lines, then selecting relevant mutation operators, and selecting relevant tests.

## Actor
RooCode Agent

## Preconditions
- Eligible mutation targets have been identified.
- Cosmic Ray configuration and database files are available.

## Flow
1. **Line-Based Mutation Filtering**
   - Agent restricts mutation testing to changed line ranges.
   - Agent follows the steps defined in **Use Case 03.3.1 – Apply Line-Based Mutation Filtering**.

2. **Mutation Operator Selection**
   - Agent selects relevant mutation operators for targeted mutation testing.
   - Agent follows the steps defined in **Use Case 03.3.2 – Select Relevant Mutation Operators**.

3. **Test Selection**
   - Agent identifies test files that correspond to each mutated module (e.g., test_module.py for module.py).
   - Agent updates the `test-command` in the Cosmic Ray configuration file to execute all identified test files, ensuring comprehensive coverage of the mutated code.

Note:
- For clarification on filter behavior or configuration, agent should consult:
  https://cosmic-ray.readthedocs.io/en/latest/how-tos/filters.html#using-filters
  
## Verification
- Mutation configuration reflects restricted line ranges, operators, and test selection.

## Postconditions
- Mutation testing scope is minimized to relevant code, operators, and tests.
- The optimized configuration is ready for execution by the parent use case.
