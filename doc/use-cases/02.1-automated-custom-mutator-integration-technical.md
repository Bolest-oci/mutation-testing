# Technical Reference for Use Case 02.1

## Description
This document provides the technical commands and details for Use Case 02.1: Automated custom mutator integration.

## Commands and Implementation

### 1. Environment Setup and Dependency Installation
This command chain creates a virtual environment, activates it, and installs Cosmic Ray and any number of custom mutators.

- **On Windows (Command Prompt):**
  ```bash
  python -m venv .venv && .\.venv\Scripts\activate && pip install cosmic-ray && pip install -e <path\to\your\custom-mutator1> && pip install -e <path\to\your\custom-mutator2> ...
  ```

- **On Windows (bash) and similar environments:**
  ```bash
  python -m venv .venv && source .venv/Scripts/activate && pip install cosmic-ray && pip install -e <path/to/your/custom-mutator1> && pip install -e <path/to/your/custom-mutator2> ...
  ```

- **On macOS and Linux:**
  ```bash
  python -m venv .venv && source .venv/bin/activate && pip install cosmic-ray && pip install -e <path/to/your/custom-mutator1> && pip install -e <path/to/your/custom-mutator2> ...
  ```

### 2. Finding and Configuring Cosmic Ray
A Cosmic Ray configuration file might not be named `cosmic-ray.toml`. A reliable method to locate it is to search for `*.toml` files that contain the string `[cosmic-ray]`.

To use custom mutators, you need to modify the configuration file. Below are examples for single and multiple mutators.

**Single Custom Mutator:**
```toml
[cosmic-ray.filters.operators-filter]
exclude-operators = [
  "^(?!<module_name>/<operator_key>).*$",
]
```
- Replace `<module_name>` and `<operator_key>` with the values for your mutator.

**Multiple Custom Mutators:**
```toml
[cosmic-ray.filters.operators-filter]
exclude-operators = [
  "^(?!(<module_name_1>/<operator_key_1>|<module_name_2>/<operator_key_2>|...)).*$",
]
```
- Add each mutator to the regex pattern, separated by a `|`.

### 3. Finding the Operator Key
To identify the correct `<operator_key>`, inspect the `provider.py` file within the custom mutator's package. The key is defined in the `_operators` dictionary.

For example, in `tuple_shortener/provider.py`:
```python
class Provider:
    _operators = {"shorten-tuple": ShortenTuple}
```
The `<operator_key>` is `shorten-tuple`.

### 4. Running Mutation Testing and Generating a Report
This command chain runs the mutation testing process and generates an HTML report.

- **On Windows (Command Prompt):**
  ```bash
  .\.venv\Scripts\activate && cosmic-ray init <path\to\your\config.toml> session.sqlite --force && cr-filter-operators session.sqlite <path\to\your\config.toml> && cosmic-ray exec <path\to\your\config.toml> session.sqlite && cr-html session.sqlite > <report-name>.html
  ```

- **On Windows (bash), macOS, and Linux:**
  ```bash
  source .venv/Scripts/activate && cosmic-ray init <path/to/your/config.toml> session.sqlite --force && cr-filter-operators session.sqlite <path/to/your/config.toml> && cosmic-ray exec <path/to/your/config.toml> session.sqlite && cr-html session.sqlite > <report-name>.html
  ```
