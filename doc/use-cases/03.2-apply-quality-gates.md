# Use Case: 03.2 – Apply Quality Gates

## Description
This use case describes how basic quality gates are applied to changed code before mutation testing is performed.  
Quality gate decisions are enforced by explicitly excluding affected mutation jobs from execution using database-level mutation filtering.

## Actor
RooCode Agent

## Preconditions
- Relevant files and line ranges have been identified.
- The project may contain tooling or artifacts for quality checks.
- A Cosmic Ray mutation database exists.

## Flow
1. **Linting and Basic Static Checks**
   - Agent determines whether the project defines any basic quality or linting checks.
   - If no linting or static analysis tooling is available, this step is skipped without failing the use case.
   - If such checks exist, agent executes them only on the affected files and line ranges.
   - Files or line ranges that fail these checks are excluded from mutation testing by following  
     **Use Case 03.2.1 – Exclude Mutation Jobs via Database Filtering**.

2. **Coverage Evaluation**
   - Agent determines whether code coverage information is available.
   - If coverage data is not available, the coverage gate is skipped without failing the use case.
   - If coverage data is available:
   - Code with zero coverage is excluded from mutation testing by following  
     **Use Case 03.2.1 – Exclude Mutation Jobs via Database Filtering**.
   - Code with low coverage may be deprioritized or marked with a warning.

3. Agent produces a refined list of files and line ranges eligible for mutation testing.
   - If no quality gate tooling is available at all, the original candidate set is passed through unchanged.

## Verification
- All remaining mutation targets have passed applicable quality gates or were allowed to pass due to unavailable tooling.
- Mutation jobs excluded by quality gates are marked as skipped in the mutation database.

## Postconditions
- Only stable and test-relevant code remains eligible for mutation testing.
- Excluded files or lines are recorded with explicit reasons for exclusion.
