# 4.0 I want to evaluate the results of mutation tests,  
to understand how effective my existing test suite is and identify weak spots that allow mutants to survive.

# 4.1 I want to automatically clean and verify the codebase before evaluating results,  
to avoid wasting time analyzing irrelevant, unreachable, or dead code and ensure the evaluation focuses only on real, testable logic.

# 4.2 I want to generate structured mutation testing reports and interpret their outcomes,  
to see the number of killed, surviving, and equivalent mutants, calculate mutation scores, and receive suggestions for strengthening weak tests or improving related code.
