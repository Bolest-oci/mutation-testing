# 0.0 I want a system that will help me with mutation based testing for existing python projects. 
Specifically in the areas of:
- project and framework setup
- integration of custom mutators
- targeted mutation test runs
- mutation test evaluation
- help with fixes/additions to existing tests 
- help with fixes of existing codes

# 0.1 I want to use RooCode as main interface when performing these tasks, to simplify interaction with the process
