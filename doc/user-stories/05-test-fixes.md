# 5.0 I want a system that helps me identify weaknesses in existing tests revealed by mutation testing,
so that I can efficiently improve test coverage and effectiveness.

# 5.1 I want the system to analyze surviving mutants and map them to specific test gaps,
to understand why the current tests failed to kill them.

# 5.2 I want suggestions for new or improved test cases that would kill surviving mutants,
including edge cases, missing assertions, and incorrect test logic.

# 5.3 I want assistance modifying existing tests rather than always creating new ones,
to keep the test suite concise and maintainable.

# 5.4 I want to run verification mutation tests after test fixes to confirm improvements.
